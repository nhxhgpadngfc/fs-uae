## Overview

FS-UAE is a highly accurate cross-platform Amiga emulator based on UAE, providing cycle-exact hardware simulation of Amiga 500, 1200, 4000, and CD32 models. It includes a built-in WHDLoad game database for one-click setup of thousands of Amiga titles, a graphical configuration interface, save-state support, and optional network play via FS-UAE Launcher.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **FS-UAE** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Cycle-Exact Accuracy** | Hardware-accurate timing simulation across all supported Amiga models |
| **Multiple Amiga Models** | Emulates A500, A600, A1200, A4000, and CD32 with correct chipsets |
| **Game Database** | Built-in WHDLoad and curated game database with artwork and metadata |
| **Network Play** | Online multiplayer via FS-UAE Launcher network infrastructure |
